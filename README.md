# Retomá — Landing page

Landing de **Retomá**, implementada en HTML, CSS y JavaScript sin dependencias ni build, a partir del diseño de Figma (frame "Landing Page Retoma", 1920 px).

## Estructura

- `index.html` — contenido de la página
- `styles.css` — estilos (medidas tomadas del diseño)
- `script.js` — escalado del layout entre 768 y 1343 px y carrusel de historias
- `assets/` — imágenes, íconos y tipografías (Lato)

## Verla en local

Abrir `index.html` en el navegador, o servir la carpeta:

```bash
python -m http.server 5173
```

## Deploy en Vercel

Importar el repositorio en Vercel con el preset **Other**, sin comando de build y con el directorio raíz como salida.
